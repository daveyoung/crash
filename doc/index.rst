crash utility documentation
===========================

.. image:: _static/crash.jpg
   :alt: crash utility
   :width: 320

The **crash** utility is a tool for interactively analyzing the state of the
Linux system, whether it is running (a live system) or has crashed and
produced a core dump (a *dumpfile*).

* `crash command help pages <help.html>`_
* `White Paper: Crash Utility <whitepaper.html>`_
* `crash source code <https://github.com/crash-utility/crash>`_
* `GitHub releases <https://github.com/crash-utility/crash/releases>`_
* `crash-utility mailing list
  <https://lists.crash-utility.osci.io/admin/lists/devel.lists.crash-utility.osci.io/>`_
